# SaaS Incremental

Build and run a software business in your browser.

Choose your customers, develop a product, and grow its backend from a simple monolith. Balance pricing, marketing, development, security, reliability, technical debt, and cash. Stay small and profitable or raise investment to grow.

**[Play on GitHub Pages](https://mbaris.github.io/saas-incremental/)**

Designed for desktop Chrome. Progress saves automatically in your browser.
